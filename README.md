## How to Use:
- copy the github link
- paste it in your preferred LLM and prompt it to create fill-in-the-blank questions. Focus on a topic if you'd like. Prompt as necessary.

## Practice notebooks and checkers

The [YouHateYourself](YouHateYourself/) folder are practice exercises meant to be checked with their respective Python (`.py`) checker. Match each exercise to the checker for the same module.

Easiest way to do this is by cloning the repository. 
```sh
git clone https://github.com/itsriffchan/mla-context-files.git
```
Otherwise, just download the necessary files.

---

For Module 5:

1. Fill in [m5-practice.ipynb](YouHateYourself/m5-practice.ipynb) and save your changes.
2. With Python 3 installed, run this command from the folder containing this README (assuming the cloned repo):

   ```sh
   cd YouHateYourself
   python m5-checker.py m5-practice.ipynb
   ```

3. Review the failed checks, revise your answers, save, and run the checker again. If you saved your notebook under a different name, replace the notebook path in the command.

The Module 5 checker reads saved code and looks for expected patterns; it does not execute the notebook. A failed check can also mean your code differs from the expected form, even if it is otherwise valid Python. That is by design to enforce exact codes from the modules.
